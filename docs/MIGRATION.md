# 출처 추적 방식 변경 기록

## 교차검증 재확인의 빨간색 표시 (2026-11-14)
- 최신 사용자 요청으로 빨강 보류 정책을 변경했다. 근거가 있는 서술 충돌/인용 표현 차이 후보만 빨간 교차검증 필요로 표시하며 진위나 왜곡을 확정하지 않는다.
- 서버 후보/확정 표시 필드·공통 표현·인용 관계 대조와 정확한 관련 보도 이동을 추가했다. 기존 6개 카드·주장/근거·단어/문장 선택을 유지한다.
- data_version/health/캐시를 source-tracing-v1.8로 올린다. 추가 API 호출 없이 기존 비교 호출을 사용한다. 적용은 서버 재시작·확장 재빌드/새로고침·다시 분석이다.


## 일반 사이트 선택·단어 뜻/문맥 (2026-11-14)
- 선택 팝업을 일반 HTTP(S) 페이지·프레임으로 확대하고 원문을 먼저 표시한다. 본문 추출 실패/범위 밖 선택은 실제 DOM 발췌로 분석한다. 기존 Hover 범위·고정 팝업·바깥 닫기 동작은 유지한다.
- WordRequest/WordAnalysis 및 /api/words/explain, 사전 검색·인용 대조·문맥 검증·별도 캐시를 추가했다. 별도 사전 API 키는 요구하지 않고 기존 Gemini/Tavily를 쓴다.
- 기존 선택 API는 article 기본 scope를 유지하고 page_excerpt를 추가했다. 발췌와 단어 결과는 전체 기사 인덱스를 덮어쓰지 않는다. manifest HTTP 접근과 리소스 공개 범위가 바뀌므로 서버 재시작·재빌드·확장 권한 확인·기사 F5가 필요하다.


## 신뢰 지수에서 출처 확인·주의 상태로 변경 (2026-11-14)
- 기존 숫자 계산·가중치·퍼센트·점수 막대를 제거했다. 패널/기사 배지는 같은 3색 상태와 주의 목록을 공유한다. 사실/거짓 판정, 매체 신뢰 등급과 빨간색은 없다.
- 핵심 원문·출처 연결 부족과 검색 실패는 정보 부족으로, 익명·재인용·해석/예측·검색 완료 후 미발견은 실제 사유로 표시한다. 알려진 주의와 미완료가 함께 있으면 둘 다 표시한다. 원자료 나이·부가 프로필·보도 차이 수 등은 자동 감점하지 않는다.
- 입력 API·서버 분석과 다른 카드·최근 주장/근거 연결을 보존했다. 추가 모델 호출 및 지연 분석 기능은 추가하지 않았다. 적용은 재빌드·확장 새로고침·기사 F5가 필요하다.

## 확장 연결 만료 안내·주의사항 반복 정리 (2026-11-13)
- Hover·문장 선택의 메시지 전송과 초기 import에서 연결 만료를 처리하며 F5 안내를 제공한다. 만료 확인 후 통신을 반복하지 않는다. 기존 페이지에 남아 있는 이전 스크립트 교체에는 사용자 새로고침이 필요하다.
- 주의사항 상세에서 같은 이유/출처 참조를 합치고 미확인 항목·검색 오류를 각각 모았다. 빈 구역과 고정 확인 목록을 제거했다. 원본 분석 데이터와 다른 카드 정보는 보존한다.
- 이번 변경은 확장 표시·오류 처리 수정이다. 백엔드 분석 순서·호출 수·타임아웃·캐시·API 계약은 이전 작업 상태를 유지한다. 클릭 시 상세 분석은 검토 방안이며 미구현이다.

## 제목 카드 문구·Hover 경량화 (2026-11-13)
- 제목의 의미/이유 소제목을 분리하고 이유를 내용·한정 표현을 보존한 간결한 표현으로 표시한다. 기사 원문 인용은 보존한다.
- Hover의 주요 주장·근거·출처·주의사항 상세를 제거하고 대기를 250ms로 줄였다.
- Preview는 기사 추출까지만 반환하며 상세 분석은 그 추출을 재사용한다. 외부 검색을 기다리지 않지만 실제 모델 생성 시간 자체의 단축을 보장하는 것은 아니다.
- 응답/캐시 버전은 source-tracing-v1.7로 올렸으며 적용 시 서버 재시작·확장 재로드·다시 분석이 필요하다.

## 제목 의미·이유와 맥락 표현 추가 (2026-11-13)

- Gemini의 기존 추출 프롬프트, Pydantic·TypeScript·응답 검사·JSON Schema·Mock·시연 데이터를 함께 갱신했다. 이유 인용은 실제 본문으로 검사하고 출처 ID는 서버가 채운다.
- 타임라인은 짧은 label과 주요 사건 표시를 추가하며 원문·날짜·본문 위치는 보존한다.
- data_version/캐시/health를 source-tracing-v1.6으로 갱신했다. 적용하려면 서버 재시작·확장 재로드 후 다시 분석해야 한다.
- 로컬 feat/title-meaning-context에서 작업했으며 커밋·Push·PR·Merge는 수행하지 않았다.

## 중복 선택 권한 경고 정리 (2026-11-13)
- 필수 host_permissions의 https://*/*와 중복된 optional_host_permissions 항목을 제거했다. 기존 필수 권한 범위는 유지한다.
- 동일 권한의 중복 등록을 npm test 회귀에 추가했다. 동적 모듈 의존성 선언과 실제 MV3 로딩 검사도 유지한다. Chrome 오류 목록의 과거 import 실패와 현재 재현되는 오류는 구분해 확인해야 한다.

## 문장 선택 팝업 유지 방식 수정 (2026-11-13)
- Hover와 selection 모드를 분리해 선택 버튼·분석 중·결과 화면을 마우스 이탈로 닫지 않는다. 선택 분석 중 다른 기사 링크에 마우스를 올려도 기존 요청의 표시 상태를 유지한다.
- 문장 선택 팝업은 바깥 클릭·닫기·Escape로 닫는다. 선택 제스처 직후 click으로 바로 닫히거나 기존 선택이 남은 바깥 버튼 클릭으로 다시 열리는 것을 막는다. 닫은 뒤의 늦은 응답은 표시하지 않는다.
- Hover의 500ms 지연·이탈 닫기는 유지한다. 응답을 보류한 브라우저·실제 MV3 회귀로 대기 중 이동/다른 링크 Hover/바깥 닫기/늦은 응답을 확인한다. 서버 API와 요청 취소 계약은 변경하지 않는다.
