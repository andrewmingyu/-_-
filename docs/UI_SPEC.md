# UI 명세 — 출처 추적
현재 HTML/CSS/JavaScript UI를 보존한다. 이미지 시안은 배치 참고이며 예전 사실 판정 문구는 적용하지 않는다.

## 상세 패널 공통
상단 브랜드/설정/다시 분석, 기사 제목·언론사·기자, 제목의 의미와 이유 카드, 출처 확인·주의 상태·근거 현황·시연 안내, 기사 요약·분석 상태, 6개 카드, 제목·본문 표현 차이/안내 순서.
상단은 요약을 왼쪽에, 더 작은 기사 기본 정보 카드를 오른쪽에 배치한다. 요약은 1~2문장을 글머리표로 표시한다. 기존 문단 응답도 문장 경계로 나누며 소수점에서 자르지 않는다. 320px에서도 이 배치를 유지하고 각 영역 안에서 줄바꿈한다.
아래에는 나머지 5개 카드를 배치한다. 배경은 날짜·짧은 설명의 네모와 화살표로 표시하며 원문은 상세에서 확인한다. 좁은 폭에서 흐름 영역만 가로 스크롤한다. 680px 이상에서는 주장/근거를 2열로, 배경/주의할 것/관련 기사를 전체 폭으로 표시한다. 각 카드 우측에 독립 button을 둔다.
카드 헤더는 옅은 청색, 주의할 것 헤더는 주의 색상을 사용한다. 시안 하단의 전역 자세히 보기 대신 기존 카드별 자세히 보기/접기를 유지한다. 사진에 적힌 예시 분석·날짜·판단을 실제 데이터로 사용하지 않는다.
button은 aria-expanded와 aria-controls, 네이티브 Enter/Space, 포커스 표시를 가진다.
클릭 시 같은 카드 내부만 펼쳐지고 문구가 자세히 보기 › / 접기 ∧로 바뀐다.
다른 카드를 자동으로 접지 않는다. 동일 article_id 갱신에서는 펼침을 보존하고 기사 ID 변경 시 초기화한다.
분석 중과 오류 시 이전 기사 내용/제목을 숨기며 사용자 재시도를 제공한다.
loading 전용 응답은 없으며 요청 중 클라이언트가 6개 카드의 상태를 표시한다. API 실패 시 페이지에서 수집한 기본 정보와 오류·재시도 버튼을 유지한다. 서버 section_states는 카드별 ready/empty/partial/error이며 전체는 partial/complete다.

| 카드 ID | 제목 | 기본 | 상세 |
|---|---|---|---|
| context | 배경 및 맥락 | 기사 타임라인 최대 4개를 네모·화살표로 표시; 없으면 확인된 사건 하나 또는 빈 상태 | 원문 타임라인·사건·출처 링크. 원문에 없는 흐름은 만들지 않음 |

해당 데이터가 없으면 확인된 정보 없음/미확인/관련 기사 없음을 표시한다.
유명 언론사·원본 자료·주의사항 부재를 사실 확인 배지로 바꾸지 않는다.
일반적인 보도 비교는 중립 색상을 사용한다. 본문 인용과 공통 표현을 확보한 충돌 후보는 아래 재확인 기준에 따라 빨간색으로 표시한다. 공통으로 다룬 내용/표현·강조가 다른 부분을 구분하고 보도 주제·사건·인물·시점·수치·인용·강조점·배경 항목을 표시한다.
확보한 본문 발췌 비교/검색 요약 범위 비교/제목만 비교를 명시한다. 좁은 화면에서는 두 인용을 세로로 배치한다.
비교할 구절이 없거나 비교 요청이 실패해도 보도 목록은 유지한다. 기존 6개 카드와 펼침 상태는 유지하며 전역 토글이나 사실 판정 색상은 추가하지 않는다.

## Hover
콘텐츠 스크립트의 동적 import와 간접 모듈도 지원 페이지에 대해 웹 접근 가능 리소스로 선언한다. `shared/view.js`가 읽는 `shared/summary.js`도 포함해야 한다. 새 팝업을 열 때 이전 팝업의 닫기 타이머를 해제해 Hover에서 문장 선택으로 이동해도 새 팝업이 사라지지 않도록 한다.
네이버 뉴스·연합뉴스TV 페이지 안의 지원 기사 링크에서 250ms 대기 후 본문 수집·분석. 콘텐츠 스크립트 주입·웹 접근 리소스·Hover 링크 검사·워커 수집 허용 목록을 함께 유지한다. 링크 판별은 shared/article.js의 isSupportedArticleUrl()을 공유한다. 링크가 아닌 본문 제목은 Hover 대상이 아니다.
팝업은 화면 가장자리에 맞춰 배치하고 내부 스크롤한다. 이탈/닫기/Escape 시 늦은 결과를 버린다.
핵심 요약과 제목·본문 표현 차이만 제공하고 자세한 내용은 패널로 안내한다. 주요 주장·주요 근거·출처 상세·확인이 필요한 근거 목록은 표시하지 않는다. 수집 전에 워커 입력 인덱스와 서버 GET 조회·본문 해시를 확인한다.
본문 확보 실패·서버 오류를 명확히 표시한다. 기사 링크 클릭을 막지 않는다.
확장 갱신으로 runtime 연결이 끊기면 영문 예외 대신 기사 페이지 새로고침(F5)을 안내한다. 만료된 스크립트는 추가 확장/API 요청을 중단하며 페이지를 자동 새로고침하지 않는다. 초기 import 중 만료도 처리한다. 새 코드 적용에는 확장 재로드 후 기사 탭 F5가 필요하다.
키보드 focus 기반 Hover 대체 탐색·정교한 pointer 전환·실제 목록 성능 개선은 P1/P2다.

## 문장 선택
일반 HTTP(S) 페이지에서 2~3,000자 문장 선택 후 선택 원문과 문장 유형·출처 확인 버튼을 표시한다. 단어 하나는 한 글자부터 80자까지 별도 뜻·문맥 버튼을 제공한다.
사용자 클릭 전에는 선택 문장 분석을 호출하지 않는다.
선택 버튼·분석 중·결과 팝업은 마우스가 벗어나도 유지한다. 선택 팝업이 열린 동안 링크 Hover로 덮어쓰지 않는다. 팝업 바깥 클릭·닫기·Escape로 닫으며, 닫은 뒤 늦게 온 결과는 다시 표시하지 않는다. 선택을 끝내는 동일 제스처의 click은 바깥 클릭으로 처리하지 않는다. Hover 팝업은 기존 마우스 이탈 닫기를 유지한다.
선택 텍스트·추출 본문 또는 표시 범위의 발췌·앞뒤 최대 500자 문맥을 전달한다. 발췌는 context_scope=page_excerpt로 표시하고 기사 전체로 제시하지 않는다.
기존 핵심 주장 재사용과 별도 선택 분석을 구분한다. 선택 유형, 관련 출처, 원출처 상태, 근거와 연결된 주의 이유를 보여주고 원문을 자동 판정 색상으로 칠하지 않는다.
기본 드래그·복사를 유지하며 팝업 내부 선택을 재분석하지 않는다.

## 색상·안전·시연
중립 배지는 출처 상태, 주황색은 주의사항 표시용이다. 사실/거짓 의미의 하늘색·빨간색 자동 강조는 없다.
기사·AI 텍스트는 escape하고 URL은 HTTP(S)만 링크로 제공한다.
is_demo=true는 모든 결과 화면에 시연용 예시를 표시하고 가상 링크는 비활성이다.
현재 Chrome headless와 합성 DOM 검사는 통과했으나 설치된 MV3 환경·실제 네이버·화면낭독기 검사는 별도 필요하다.

## 제목의 의미와 이유 카드 (2026-11-13)
기사 제목 바로 아래 최상단에 의미 1~2문장과 순서 없는 이유 목록을 표시한다. 별도의 자세히 보기/접기는 기존 6개 카드와 독립적이다. 이유별 기사 인용과 이동 버튼을 펼치며 해당 근거 항목 또는 근거 확인 현황으로 이동한다. 이동 시 해당 카드를 열고 포커스·일시 강조를 제공한다.
배경 박스는 날짜와 짧은 label을 분리하고 주요 사건에 굵은 테두리와 주요 사건 텍스트 표지를 사용한다. label에는 줄 수 제한·말줄임을 사용하지 않는다. 긴 원문은 상세에 보존한다. 라벨이 없는 이전 응답은 주요 사건/배경 정보라는 중립 표현으로 처리한다.

## 제목 이유 표현·빠른 Hover (2026-11-13)
제목 카드는 제목의 의미라는 제목 아래 설명 문장, 이유라는 소제목 아래 글머리표를 둔다. 각 이유는 주어·핵심 내용·부정/검토/예정/가능성을 보존해 주장·경고·표명 등의 간결한 표현으로 끝낸다. 자세히 보기의 원문은 변환하지 않는다.
Hover는 250ms 대기 후 시작한다. 서버의 기사 추출 단계까지만 기다리며 외부 검색·출처 검증은 상세 패널에서 수행한다. 기존 상세 결과가 있으면 재사용한다.

## 주의사항 상세 표시 정리 (2026-11-13)
주의 이유는 공백·끝 구두점 차이까지 정리해 중복 제거하고 연결된 주장 번호와 출처를 보존한다. 자료별 같은 미확인 항목은 한 구역에 모으며, 검색 오류도 한 번만 표시한다. 내용 없는 소제목, 전체 주장 재나열, 모든 기사에 동일하게 붙이는 추가 확인 목록을 제거한다. 원문·자료별 전체 관찰은 기존 주장/근거 카드에 보존하며 서버 판정·응답 데이터는 바꾸지 않는다. 자세히 보기 시 지연 분석은 아직 구현하지 않았다.

## 출처 확인·주의 상태 (2026-11-14)
종합 신뢰 지수 대신 출처 확인·주의 상태를 표시한다. 점수·가중치·감점·퍼센트·계산 막대는 생성하거나 렌더링하지 않는다. 초록은 핵심 출처 조사 완료 범위의 별도 주의사항 없음, 노랑은 구체적 주의, 회색은 조사 전/실패/원문 및 출처 관계 부족이다. 빨강은 아래 교차검증 재확인 기준에 한해 사용한다. 색상과 상태 문구를 함께 표시한다.
익명·재인용·해석/예측 등 실제 사유를 관련 주장 번호와 출처와 함께 3개까지 보여준다. 미완료와 주의가 겹치면 주의 색상과 미완료 이유를 함께 표시하며 빨간 재확인 안내가 노란 주의보다 우선한다. 자세히 보기는 기존 주의사항 카드를 열며 다른 카드의 펼침은 보존한다. 기사의 사실/거짓 및 언론사 등급을 판정하지 않는다는 안내를 유지한다.
기사 옆 자동 배지·배지 팝업·패널은 같은 sourceNotice()를 사용한다. 관련 기사 비교 수·공통/차이 개수·제목 글자 겹침·작성일 나이·매체/작성자 표기는 색상 요인이 아니다. 제목 차이·비교·날짜는 기존 설명 카드에서 유지한다.

## 일반 사이트 드래그·단어 (2026-11-14)
본문 추출 실패/불일치를 이유로 팝업을 조용히 종료하지 않는다. DOM 선택 원문을 확인하고 주변 문맥을 발췌해 표시한다. 분석 전·로딩·오류·완료 모두 선택 텍스트를 보존한다. 마우스 이동 중 유지, 바깥 클릭/닫기/Escape 종료와 늦은 응답 무시는 유지한다.
단어 팝업은 선택 단어/표제어, 사전 자료의 의미 또는 AI 일반 의미(사전 미확인), 이 문맥에서의 의미, 실제 사전 링크/인용과 문맥 인용을 구분한다. 검색 요약만 확보한 경우 원문 미확인을 표시한다. 실제 사전 자료가 없는 Mock은 시연용·일반 의미임을 표시하고 실제 사전 정의를 제공했다고 하지 않는다.

## 교차검증 필요의 빨간색 안내 (2026-11-14, 앞선 빨강 보류 규칙을 대체)
sourceNotice.level=review는 🔴 교차검증 필요다. 기사 진위/낮은 신뢰 등급이 아닌 재확인 요청이다. 이유에는 비교 기사 제목과 어떤 대조가 필요한지, 해당 기사 링크·두 기사 대조 보기 버튼을 표시한다. 버튼은 related 카드를 열고 해당 기사 details만 펼치며 다른 카드 상태를 보존한다.
보도 상세는 현재 기사/비교 보도 인용과 공통 비교 표현, 원문/검색 요약 범위를 함께 표시한다. 원문과 조건·인용 표현에 차이가 있으면 왜곡 여부 확인 필요로 표시한다. 왜곡했습니다라고 단정하지 않는다. 원문 미확보/맥락 미확인은 노랑, 단순 강조 차이는 기존 중립 표시다.

## 원격 main의 외신 기능 통합 (2026-11-14)
기준 원격 main은 cd1794e(PR #8 외국기사 번역, PR #9 외신 검색/원문 대조/관련 기사 필터/작성일 추출)다. 내 기능의 보관 커밋은 bedc691이며 feat/source-caution-update에서 병합한다.
외신/기관 도메인 검색, 영어 검색어·후속 보도 검색, 관련 기사 필터·정렬과 작성일 추출을 보존했다. 주장/근거의 한국어 번역과 비교 구절의 번역/차이 설명은 원문과 분리한다.
사용자 선택에 따라 상단 ‘원문과 다른 점’ 카드를 유지하고 빨간 재확인 안내와 관련 기사 이동을 연결한다. 기존 6개 카드의 독립 토글·고정 선택·단어 API는 유지한다.
공식 매체 도메인과 추정 번역의 단어 유사성은 원문 후보 선정에만 사용한다. 실제 인용 관계/원본 확인으로 자동 승격하지 않는다. 원문 후보는 상단 카드에서 ‘인용 관계 미확인’으로 구분하고 두 인용·AI 번역·차이 설명을 제공한다. 직접 링크 등 실제 연결 근거와 원자료 관찰이 확인될 때만 기존 출처 확인 로직을 적용한다.
신뢰 지수·가중치(귀속 차이 3배 포함)는 사용하지 않는다. 서술 충돌의 빨강/요약 수준의 노랑은 기존 재확인 조건을 따른다. 원문 후보라는 이유만으로 빨강이 되거나 실제 인용 원본이 되지 않는다.
두 브랜치가 각각 1.8을 사용했으므로 통합 후 data_version/health/캐시는 source-tracing-v1.9다. 서버 재시작 → npm run build → 확장 새로고침 → 기사 F5 → 다시 분석으로 적용한다.
