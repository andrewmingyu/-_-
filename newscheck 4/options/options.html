뉴스체크 AI 설정

키는 이 브라우저에만 저장되고, 분석 요청을 보낼 때만 사용돼요. 키가 없어도 자극 키워드·작성 스타일 분석은 동작해요.

AI 모델 기능 1·2·4에 사용

비워 두면 기본 모델을 써요. 모델이 없다는 오류가 나면 제공자 문서에서 최신 모델 이름으로 바꿔 주세요.

네이버 검색 API 기능 2·4·5에 사용

기자의 최근 기사와 같은 사건을 다룬 다른 기사를 찾을 때 써요. 네이버 클라우드 플랫폼 콘솔 → Services → NAVER API HUB에서 Application을 만들고 '검색 - 뉴스'를 선택하면 발급돼요. (예전 개발자센터 키도 그대로 넣으면 동작해요.)
