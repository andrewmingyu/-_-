# 뉴스체크 AI (크롬 확장 프로그램)

뉴스 기사 페이지에서 툴바 아이콘을 누르면, 오른쪽 사이드 패널 한 페이지에 기사의 신뢰도(%)와 근거를 보여줍니다.

## 설치
1. 압축을 풀고 크롬 주소창에 `chrome://extensions` 입력 → **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → `newscheck` 폴더 선택
3. 기사 페이지에서 아이콘 클릭 (업데이트할 땐 폴더를 덮어쓰고 확장 카드의 새로고침 ↻)

키 없이 화면을 보려면 설정 화면의 **데모 화면 보기** (가상 기사 데이터).

## API 키 (선택, 아이콘 우클릭 → 옵션)
| 키 | 쓰이는 곳 | 발급 |
|---|---|---|
| AI (Gemini/OpenAI/Claude) | AI 제목 생성, 주장 추출·대조, 교차검증 | Gemini는 aistudio.google.com 무료 |
| 네이버 검색 API | 다른 보도 검색, 주장별 근거 검색, 기자 최근 기사 | 네이버 클라우드 콘솔 → NAVER API HUB → Application → 검색 - 뉴스 (예전 개발자센터 키도 호환) |

키가 없으면 규칙 기반(자극 표현, 출처 표현, 날짜)만으로 계산하고 '잠정'으로 표시합니다.

## 화면 구성 (한 페이지)
1. 기사 정보: 언론사 · 기자 · 작성일 + **오늘 기준 며칠 전** (1년 이상이면 경고)
2. **신뢰도 %** + 한 줄 결론 + 기준 4줄 (누르면 근거 펼침)
3. **제목 비교**: 원제목(자극 표현 표시) vs AI가 본문만 보고 쓴 제목
4. **확인이 필요한 주장**: 다른 보도와 충돌하거나 근거가 없는 주장만
5. **근거 자세히 보기** (접힘): 요약, 주장 전체, 다른 보도, 출처 지표, 자극 표현, 사진 확인

## 신뢰도 계산 (`lib/analysis.js` computeCredibility)
신뢰도 = 교차검증 × 40% + 글쓴이·출처 × 25% + 자극적 표현 × 20% + 날짜 × 15%

| 기준 | 측정 |
|---|---|
| 교차검증 | 주장별 대조(일치 100 / 근거 없음 40 / 충돌 0) 70% + 같은 사건 보도 언론사 수(5곳↑ 90, 3~4곳 80, 1~2곳 55, 0곳 20) 30% |
| 글쓴이·출처 | 주장의 출처 유형 평균(공식 100, 실명 80, 익명 45, 없음 30, SNS 25) + 기자 실명 +5 / 없음 −15, 기자의 감정 자극 제목 40%↑ −10 |
| 자극적 표현 | 100 − 제목 자극도 (AI 판단 우선), 본문 감정 단어 밀도 감점 |
| 날짜 | 7일 이내 100, 30일 85, 1년 65, 그 이상 45, 사진 촬영 시점 불일치 −15, 예전 기사 재사용 −15 |

- 확인 못 한 기준은 제외하고 비율 재조정, '잠정' 표시
- 충돌하는 주장이 있으면 최대 60%
- 80↑ 신뢰 근거 충분 / 60~79 대체로 신뢰할 만함 / 40~59 주의해서 읽기 / 40 미만 신뢰 근거 부족

### 자극 표현 판정
- **감정 단어**(충격, 경악, 날벼락…): 항상 감점
- **사실 단어**(사망, 폭락, 참사…): 본문이 사실로 뒷받침하면 감점 안 함. "사망설", "사망 여부"처럼 소문·의혹을 가리키는 쓰임은 사실로 보지 않음
- AI가 쓴 담백한 제목에도 들어가는 단어는 불가피한 표현으로 보고 감점 안 함
- 사전과 가중치는 `SENSATIONAL_WORDS`, `FACT_WORDS`에서 수정

## 코드 구조
| 파일 | 역할 |
|---|---|
| `lib/extract.js` | 기사 추출(제목·본문·기자·날짜·사진), 본문 하이라이트, 주장 문장 찾기 |
| `lib/analysis.js` | 규칙 기반 분석, 신뢰도 계산 |
| `lib/llm.js` | AI 프롬프트 (제목 생성, 주장 추출, 주장 대조, 교차검증) |
| `lib/naver.js` | 네이버 뉴스 검색 (API HUB → 기존 방식 자동 전환) |
| `sidepanel/` | 한 페이지 화면 |
| `data/press.json` | 언론사 도메인 → 이름 |
| `data/demo.json` | 데모용 가상 데이터 |

## 한계
- 주장 대조는 다른 기사의 전문이 아니라 검색 결과의 제목·요약문만 비교
- 여러 언론사가 같은 오보를 옮겨 쓰면 '일치'로 나올 수 있음
- 기자 최근 기사는 이름 검색이라 동명이인이 섞일 수 있음
- 가중치(40/25/20/15)는 팀이 정한 출발값이며 테스트하며 조정
